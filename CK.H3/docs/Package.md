An idiomatic C# wrapper around Uber's H3 hierarchical hexagonal geospatial indexing library: H3Index, LatLng, CellBoundary, CoordIJ and the H3 static class, with native errors raised as H3Exception.

This package contains no native binary: CK.H3.Binaries brings the prebuilt h3 library.

See the [README](https://github.com/signature-opensource/CK-H3/blob/stable/README.md).
